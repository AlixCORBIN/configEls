# img:
Créait une image qui sera automatiquement chargé, avec la source passé en paramètre. C'est un élément de type *img*.

## minimum:
```javascript
{
	type:"img",
	src:"/imgs/img.png"
}
```

le *src* accepte tous les types d'images de type *PNG*/*JPG*/*SVG*/ou encore *base64*.

## options supplémentaires:
```javascript
{
	id:"element id",
	style:"/* std css */",
	title:"description visible au survol de la sourie"
}
```
