# title:
Créait un élément titre, avec le texte passé en paramètre. C'est un titre niveau *h3*.

## minimum:
```javascript
{
	type:"title",
	text:"Mon Titre"
}
```

## options supplémentaires:
```javascript
{
	id:"element id",
	style:"/* std css */",
	title:"description visible au survol de la sourie"
}
```
