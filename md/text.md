# text:
Créait un élément texte, avec le texte passé en paramètre. C'est un élément de type *p*.

## minimum:
```javascript
{
	type:"text",
	text:"un texte comme un autre"
}
```

## options supplémentaires:
```javascript
{
	id:"element id",
	style:"/* std css */",
	title:"description visible au survol de la sourie"
}
```
